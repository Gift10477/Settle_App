# SettleIn frontend

React student portal and administrator dashboard. Run `npm.cmd install` and `npm.cmd run dev` here after starting the backend and MySQL. Open http://localhost:5173.

See [project setup](../README.md) for the isolated database, administrator setup and application workflows. This checkout's local admin credentials are in `server/admin-access.local.txt`, excluded from Git. Sign in and choose **Admin panel**.

Run `npm.cmd run build` to build and `npm.cmd test` for the frontend tests.
